강의 분석 및 퀴즈 생성

AI로 어려운 강의 내용을 이해하고 복습 퀴즈로 배운 내용을 확인해 보세요.

① 활용 상황 설명

대학 수업에서 이해하기 어려웠거나 더 알아보고 싶은 부분이 있을 때 AI를 활용해 보세요.

아래 두 프롬프트를 복사한 뒤 과목, 학습 수준, 목표, 출제 범위를 자신에게 맞게 바꿔 쓸 수 있어요.

② 활용 방법

  1. 1. 공유할 수 있는 강의자료(PDF, 필기 등)를 업로드합니다.

  2. 2. 자신의 학습 수준과 목표를 프롬프트에 포함합니다.

  3. 3. 이해되지 않는 개념을 단계별로 설명해 달라고 요청합니다.

    [5-1] 강의 이해 프롬프트

    너는 대학생을 가르치는 전문 튜터야. 첨부한 강의자료를 바탕으로 내용을 설명해 줘. [학습 정보] - 학습 수준: 대학교 2학년 - 과목: 컴퓨터구조 - 학습 목표: CPU 데이터패스 이해 [요청사항] 1. 강의자료의 순서대로 설명해 줘. 2. 어려운 개념은 쉬운 예시를 들어 설명해 줘. 3. 중요한 용어는 영어와 한국어를 함께 표시해 줘. 4. 강의자료에 없는 내용은 별도로 구분해 줘. 5. 마지막에 핵심 개념을 정리해 줘.

  4. 4. 학습한 범위에서 복습 퀴즈를 출제해 달라고 요청합니다.

    [5-2] 퀴즈 생성 프롬프트

    첨부한 강의자료를 기반으로 복습 퀴즈를 만들어 줘. [조건] - 난이도: 대학교 2학년 - 문제 수: 10문제 - 유형: 객관식 5문제, 단답형 5문제 - 출제 범위: 강의자료 10~25페이지 [진행 방식] 1. 문제를 한 개씩 출제해 줘. 2. 내가 답변하기 전까지 정답을 공개하지 마. 3. 답변 후 정답과 해설을 제공해 줘. 4. 틀린 문제와 관련된 개념을 다시 설명해 줘.

  5. 5. 틀린 문제를 분석하고 관련 개념을 다시 공부합니다.

검증 방법 AI의 설명과 퀴즈 정답을 원본 강의자료와 대조하세요.
